# WBS 還是 Activity？

一款給專案管理課堂使用的手機優先分類遊戲。玩家在 30 秒內完成 10 題，將項目左滑分類為 WBS，或右滑分類為 Activity；也可以使用畫面按鈕或鍵盤方向鍵。

## 開始遊戲

直接以瀏覽器開啟 `index.html`，不需安裝套件或啟動伺服器。遊戲可在 GitHub Pages 等靜態網站服務上發布。

## 遊戲規則

- 左滑／按「WBS」／按鍵盤 ←：可交付成果或其組成部分
- 右滑／按「Activity」／按鍵盤 →：為產出成果而執行的工作
- 10 題限時 30 秒；答對得 10 分，連續答對可累積額外連擊分
- 結束後可檢視每題答案和簡短理由

## 檔案

- `index.html`：頁面結構與無障礙語意
- `styles.css`：響應式視覺與滑動卡片動畫
- `game.js`：題目、計時、手勢、計分與答案解析
- `PROJECT.md`：專案目標與設計規範
